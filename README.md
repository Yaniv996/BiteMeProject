# "Bite Me" Application 
Desktop app that provides a user-friendly platform for customers to browse menus, order food and track deliveries. While enabling restaurants to manage their menus, handle incoming orders, and coordinate deliveries. Developed with  MySQL and Java in the backend and Java and JavaFX in the frontend.
